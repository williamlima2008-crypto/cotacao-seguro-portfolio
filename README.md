# cotacao-seguro-portfolio
Projeto web de cotação de seguro desenvolvido para cliente.

## 📋 Sobre o projeto

Aplicação web desenvolvida para facilitar o preenchimento de informações para cotação de seguro veicular.

O projeto foi desenvolvido para um cliente e apresenta uma interface organizada, com foco em facilitar o preenchimento do formulário e a coleta das informações necessárias para a cotação.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts

## ✨ Características

- Formulário de cotação de seguro veicular
- Interface responsiva
- Layout organizado e intuitivo
- Campos estruturados para coleta das informações do cliente
- Interface adaptada para diferentes tamanhos de tela
- Design personalizado para o projeto

## 🎯 Objetivo

O objetivo do projeto foi criar uma solução web simples e prática para auxiliar no processo de cotação de seguro veicular.

Além da aplicação prática, este projeto faz parte do meu portfólio profissional de desenvolvimento.

## 👨‍💻 Desenvolvimento

Durante o desenvolvimento foram realizados trabalhos de implementação da interface, organização do formulário, ajustes visuais e correções de problemas encontrados durante o desenvolvimento.

## 📌 Observação
